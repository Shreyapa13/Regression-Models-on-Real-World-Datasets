# Regression Models on Real-World Datasets

This repository contains practical implementations and experiments related to **Regression Models and Data Pre-processing** using real-world datasets.

The project focuses on understanding the complete workflow of preparing data, applying pre-processing techniques, and building regression models for predictive analysis.

## 📌 Project Overview

The notebooks in this repository demonstrate different stages of a machine learning workflow, including:

* Data pre-processing
* Preparing datasets for machine learning
* Linear Regression
* Regression model implementation
* Testing and experimenting with pre-processed data
* Model-based analysis on real-world datasets

## 📂 Repository Contents

| Notebook                    | Description                                                                                            |
| --------------------------- | ------------------------------------------------------------------------------------------------------ |
| `Pre-processing.ipynb`      | Contains the data pre-processing workflow used to prepare datasets for further analysis and modelling. |
| `Test Pre-processing.ipynb` | Used for testing and evaluating the pre-processing workflow.                                           |
| `Linear Regression.ipynb`   | Demonstrates the implementation and application of a Linear Regression model.                          |
| `LR.ipynb`                  | Contains additional work and experimentation related to Linear Regression.                             |

## 🛠️ Technologies Used

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Shreyapa13/Regression-Models-on-Real-World-Datasets.git
```

### 2. Navigate to the project

```bash
cd Regression-Models-on-Real-World-Datasets
```

### 3. Install the required libraries

```bash
pip install numpy pandas matplotlib scikit-learn jupyter
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open any of the `.ipynb` files to explore the implementation.
